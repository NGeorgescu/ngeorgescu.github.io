archcrypt

Shell scripts for a full-disk-encrypted (LUKS) Arch Linux install. Run in numeric order from the Arch install ISO. Fetch the tarball with one command:

From an Arch install disk

curl -sL ngeorgescu.github.io/archcrypt.tar.gz | tar xz

Or download it manually

curl -O ngeorgescu.github.io/archcrypt.tar.gz
